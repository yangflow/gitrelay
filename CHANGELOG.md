# GitRelay 0.4.0

GitRelay is a local-first macOS workspace for keeping important Git repositories mirrored, healthy, and recoverable.

## Highlights

- A three-pane workspace keeps health filters, the Mirror list, and state-driven details visible together.
- Add Mirror supports connected-service browsing and direct Git URLs in one flow, with one source and multiple Git or archive destinations.
- Every Mirror combines credentials, policy, health, verification, activity, branches, and logs under one stable identity.
- Smart views focus attention on failures, active work, paused Mirrors, and labels without a separate queue screen.
- GitHub, GitLab, Gitea, Gitee, Bitbucket, and self-hosted Git services share one connection and account model.
- Menu bar, Widget, Shortcuts, App Intents, notifications, webhook triggers, and `gitrelayctl` use the same Mirror state.
- Destructive push checks, credential redaction, Keychain storage, per-target results, and independent verification schedules protect routine operation.
- Git LFS, release assets, tar.gz, zip, and Git bundle destinations extend continuity beyond Git refs.

## Requirements

- macOS 26.2 or later
- Apple Silicon or Intel
